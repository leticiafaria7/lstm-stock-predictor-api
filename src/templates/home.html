Endpoints da API

Os dados históricos são sincronizados diariamente com o Supabase. Após a atualização, as previsões são recalculadas utilizando os modelos LSTM treinados para cada ativo e ficam imediatamente disponíveis pelos endpoints abaixo.

Método
Endpoint
Descrição
POST
/api/v1/predict/<ticker>
Retorna o preço previsto para o próximo pregão juntamente com o último fechamento disponível.
GET
/api/v1/models
Lista todos os tickers disponíveis e informações do modelo armazenado.
GET
/api/v1/models/<ticker>/metrics
Retorna as métricas de avaliação (MAE, RMSE, MAPE, R² e demais indicadores).
GET
/health
Health Check utilizado por Load Balancer e Kubernetes.
GET
/metrics
Métricas Prometheus da aplicação (latência, erros e quantidade de requisições).

Atualização diária

Sempre que o processo de sincronização é executado são realizadas as etapas:

  • Atualização das séries históricas de ações.
  • Atualização dos índices econômicos.
  • Atualização dos ativos internacionais.
  • Construção da tabela analítica.
  • Geração das previsões para D+1.
  • Persistência das previsões no Supabase.
